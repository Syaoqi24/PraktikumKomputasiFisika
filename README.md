## 📖 About

This repository contains all Scilab (`.sce`) scripts written during the **Praktikum Komputasi Fisika** (Physics Computation Laboratory) course. The codes cover numerical methods, interpolation, root-finding, and various computational exercises organized by meeting session (*pertemuan*).

---

## 🛠️ Requirements

- **Scilab** (free, open-source) — [Download here](https://www.scilab.org/download/)
- No additional toolboxes required

To run a script:
```
File → Open → select the .sce file → press F5 or click Execute
```
