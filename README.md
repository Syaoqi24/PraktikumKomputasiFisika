---

## 📖 Tentang Repositori

Repositori ini memuat seluruh skrip Scilab (`.sce`) yang disusun selama mengikuti mata kuliah **Praktikum Komputasi Fisika**. Kode-kode yang tersedia mencakup metode numerik, interpolasi, pencarian akar persamaan, serta berbagai latihan komputasi yang diorganisasikan berdasarkan pertemuan praktikum.

---

## 🛠️ Persyaratan

- **Scilab** (gratis dan open-source) — [Unduh di sini](https://www.scilab.org/download/)
- Tidak memerlukan toolbox tambahan

Cara menjalankan skrip:
```
File → Open → pilih file .sce → tekan F5 atau klik Execute
```
